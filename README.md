# HR Policy Assistant (RAG)

An AI-powered Retrieval-Augmented Generation (RAG) assistant designed to answer queries based on HR policy documents.

## Features
- Document ingestion and indexing of HR policy guidelines
- Vector embeddings and similarity search
- Contextual answer generation with source attribution

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ai-genai-agenticai-intelligence/HR-Policy-Rag-Assistant.git
   cd HR-Policy-Rag-Assistant
   ```

2. **Set up virtual environment:**
   ```bash
   python -m venv myenv
   myenv\Scripts\activate  # On Windows
   # source myenv/bin/activate  # On Linux/macOS
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Variables:**
   Create a `.env` file with required API keys.
